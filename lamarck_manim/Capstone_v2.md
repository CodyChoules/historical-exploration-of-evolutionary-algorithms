ANALYSIS:
Project topic and description:
Pure Lamarckian Algorithm: Development, Visualization, and Comparative Analysis with Genetic and Lamarckian Genetic Algorithms. This project investigates a pure Lamarckian algorithm operating entirely within the Lamarckian paradigm (without Darwinian mechanisms) to advance understanding of evolutionary computation approaches for complex optimization problems. The algorithm uses vector representations where organisms acquire traits during their lifetime that are inherited by offspring through spawn origin blending, habit vector inheritance, and besoin-driven gradient descent. The research includes Manim visualizations comparing LA behavior against standard GA and LGA implementations on multi-dimensional optimization topologies, providing empirical analysis of when and how different evolutionary paradigms are most effective. The work contributes to the field's understanding of optimization algorithm selection and behavior, with applications spanning logistics, resource allocation, product design, and manufacturing process optimization.

Project purpose and goals:
Research contribution: Investigate and characterize pure Lamarckian mechanisms in isolation from Darwinian components, advancing understanding of evolutionary computation paradigms. The research provides empirical comparison of LA, GA, and LGA behaviors, contributing foundational knowledge to the optimization field. Understanding algorithm behavior: Systematically analyze when and why different evolutionary paradigms exhibit distinct characteristics, identifying problem types where pure Lamarckian approaches demonstrate unique advantages or disadvantages. This understanding helps practitioners make informed algorithm selection decisions based on problem characteristics rather than convention. Practical knowledge: Demonstrate how Lamarckian principles function in computational contexts, building on proven applications in molecular docking (Morris et al., 1998) and extending understanding to pure implementations. The research provides reproducible tools and visualizations that enable further investigation and practical application, contributing to the broader optimization research community.

Descriptive method:
The project uses unsupervised learning through evolutionary computation as described by Bäck (1996). Organisms are represented as vectors where the origin is initial state, endpoint is reproduction state after lifetime changes, and vector difference represents inheritable acquired traits. The algorithm describes how organisms acquire traits (purpose vector via gradient ascent or descent, habit vector from parent behavior) and how these traits are inherited (spawn origin generation, child vector formation combining purpose and habit). Comparative analysis describes behavioral patterns, convergence characteristics, and local optima escape mechanisms across LA, GA, and LGA.

Predictive or prescriptive method:
Prescriptive: The algorithm prescribes how organisms should move toward goals (purpose vector via gradient ascent) and how children should inherit parent characteristics. The comparative analysis prescribes when LA is distinct to GA/LGA based on problem characteristics. Predictive: The algorithm predicts organism trajectories and population evolution patterns. Performance metrics predict convergence behavior and solution quality outcomes.

IMPLEMENTATION and EVALUATION:
Describe how you will approach the execution of your project.
Following an adapted CRISP-DM methodology: 
(1) Problem Understanding & Literature Review - define need, review literature, establish foundations. 
(2) Algorithm Design - design pure LA architecture, specify vector representation and mechanisms. 
(3) Implementation - implement core LA algorithm using Python, JAX for gradient computation, Manim for visualizations, baseline GA and LGA for comparison. 
(4) Testing & Validation - test on multiple topologies (normal distributions, Rastrigin, Rosenbrock), validate mechanisms operate as designed. 
(5) Comparative Evaluation - run experiments 20-30 times per topology, collect metrics (convergence speed, solution quality, escape patterns), generate comparative visualizations. 
(6) Documentation & Communication - document implementation with full reproducibility, create research materials and visualizations that communicate findings clearly, write comparative analysis report with empirical findings. Performance measured through convergence metrics, local optima handling, population dynamics, and behavioral "fingerprint" analysis characterizing the distinct characteristics of each paradigm and their implications for algorithm selection. 

Success criteria:
